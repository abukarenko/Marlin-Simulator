# Easy Marlin Emulator 1.1.0 (локальная сборка)

[Готовая сборка Windows x64](https://github.com/abukarenko/Marlin-Simulator/releases/tag/easy-marlin-emulator-v1.0.0).
Распакуйте архив в отдельную папку и запустите `EasyMarlinEmulator.exe`
или `Start-Easy-Marlin-Emulator.cmd`. Установка и .NET не требуются.

Отдельный эмулятор принтера для отладки Marlin Host и других управляющих программ.
Настоящая прошивка Marlin 2.1.2.9, виртуальная плата RAMPS Native,
экран RepRapDiscount Full Graphic Smart Controller (ST7920, 128×64).
Экран формирует сама Marlin; поддерживаются штатные меню и сообщения M117.

Запуск: `Start-Easy-Marlin-Emulator.cmd`. TCP-сервер автоматически слушает **127.0.0.1:7000**,
один клиент одновременно. В Marlin Host выберите TCP и этот адрес.
COM и локального терминала в этом варианте нет. Подключение передаёт байты
непосредственно прошивке, включая checksum, Resend и emergency parser.

По умолчанию клиентская область окна 512×256 (4×). Размер изменяется
целыми множителями 128×64 от 1× до 12×. Рамка и заголовок Windows добавляются снаружи.
Порт и начальный масштаб можно указать при запуске:

```bat
Start-Easy-Marlin-Emulator.cmd --port 7001 --scale 6
```

- Колесо мыши или ↑/↓ — вращение энкодера.
- Нажатие мыши, Enter или пробел — кнопка энкодера.
- Esc или ← — кнопка «Назад», если поддерживается конфигурацией Marlin.
- K — аппаратный аварийный останов; M112 также работает через TCP.
- F1 — справка.

Чтобы сбросить прошивку после аварии, закройте и заново запустите приложение.
Отключение TCP-клиента сохраняет состояние принтера; другой клиент может подключиться снова.
EEPROM сохраняется в `eeprom.dat` рядом с программой, отдельно от старого эмулятора.
Рабочая область пока условная: 220×220×250 мм. Два независимых экструдера E0/E1
и два нагреваемых сопла T0/T1 на общей каретке, нагреваемый стол и BLTouch.
T0 — левое базовое сопло; T1 расположен на X=+46, Y=0, Z=0 мм относительно T0.
Высота сопел одинакова и выставляется механически; отдельная поправка Z для T1 не используется.
BLTouch: X=+23, Y=−44 мм относительно T0, если X направлен вправо, Y вверх на чертеже.
Z датчика установлен в −2 мм только для виртуальной модели и не является измерением реального датчика.
Включены безопасный Z-homing датчиком, bilinear-сетка 3×3, независимые настройки подачи E0/E1,
EEPROM, emergency parser и M114 realtime. Размеры, шаги/мм и параметры нагрева предварительные.
Модель нагрева и механики унаследована от исходного эмулятора.

Поддерживается управляемый STOP `M411` с контрактом `Cap:HOST_STOP:1`:
очистка очереди, выключение нагрева и вентиляторов, отвод Z до 15 мм при известной Z.
`M112` остаётся аварийным остановом. Команду M411 можно отправить из терминала хоста;
кнопка STOP в Marlin Host 1.0.5 использует канал ESP и к прямому TCP эмулятора не подключена.

## Конфигурация прошивки

Редактируемые `Configuration.h` и `Configuration_adv.h` лежат в корне проекта симулятора.
Это исходные настройки сборки: скрипт копирует их в Marlin без подмены параметров принтера.
Каталог `config/` и заголовки внутри `vendor/` — копии для совместимости и компиляции.
Сохраняйте оба исходных заголовка вместе. При несовместимых настройках проверка Marlin
остановит компиляцию. Для Windows остаётся плата `BOARD_SIMULATED`.

После изменения любого заголовка пересоберите приложение:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/Build-Lcd.ps1
```

Оба заголовка копируются рядом с `dist/lcd/EasyMarlinEmulator.exe` и входят в переносимый архив.
Если редактировались именно копии рядом с EXE, выберите их явно:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/Build-Lcd.ps1 -ConfigurationDirectory dist/lcd
```

Изменение заголовка и перезапуск готового EXE сами по себе не перекомпилируют прошивку.
Для сборки нужны исходники проекта и инструменты сборки. Параметры EEPROM могут иметь
приоритет над новыми значениями по умолчанию: `M502` загружает значения из новой сборки,
а `M500` сохраняет их. Автоматического стирания пользовательского EEPROM при сборке нет.
Пара `M502` / `M500` сбрасывает все сохраняемые параметры — применяйте её осознанно.

Параметры контроллеров, пинов и термисторов реального принтера пока не определены.
Эта конфигурация предназначена для симулятора, не для загрузки в физическую плату.

Сборка: `powershell -ExecutionPolicy Bypass -File scripts/Build-Lcd.ps1`.
Результат: `dist/lcd/EasyMarlinEmulator.exe`. Требуются зависимости исходного эмулятора;
.NET для этого отдельного приложения не нужен. Нужен совместимый OpenGL-драйвер.
Исходный эмулятор и Marlin Host собираются прежними скриптами.

Проверки готовой сборки:

```powershell
python scripts/check_lcd_dual.py
python scripts/check_lcd.py
dotnet run --project tests/MarlinHost.Tests -c Release -p:NuGetAudit=false -- --lcd
```

`check_lcd_dual.py` запускает отдельный виртуальный принтер с временным EEPROM и проверяет
T0/T1, смещения XY при общем Z, BLTouch/G28, сетку G29, независимый нагрев двух сопел,
команды подачи E0/E1, сохранение параметров и выключение обоих нагревателей через M411.
Журнал: `artifacts/lcd-dual-check.log`; снимок LCD: `artifacts/lcd-dual-check.bmp`.

`check_lcd.py` охватывает TCP, checksum/Resend, движение, нагреватели, M73,
M117, переподключение и M112 во время M109. Снимок LCD и журнал находятся в `artifacts/`.
Проверка `--lcd` использует настоящий контроллер Marlin Host: инициализация, парковка,
пауза, продолжение печати, скорость/поток и нагрев.

Упаковка релиза: `powershell -ExecutionPolicy Bypass -File scripts/Package-LcdRelease.ps1`.
Создаётся чистый переносимый архив с DLL, лицензиями, инструкцией и примерами G-code;
EEPROM и локальные настройки пользователя в архив не включаются.
Исходный код текущей версии: [Marlin-Simulator](https://github.com/abukarenko/Marlin-Simulator).
