# Четыре угла области модели — Marlin 2.1.2.8 / RAMPS Mega2560

Подготовлено 15 ноября 2026 для текущего проекта `C:\Marlin\Marlin-2.1.2.8`.
Прошивка записана на ATmega2560 через COM20 15 ноября 2026. Avrdude проверил все 146512 байт Flash. EEPROM до/после совпала побайтно; подтверждены E403.85, M206 Z1.45, M851 Y24 Z0 и поддержка FOUR_POINT_LEVELING. Новый Host 0.4 подключён. Физический замер четырёх точек этим HEX ещё не выполнялся. Логи и полные резервные копии Flash/EEPROM: `artifacts/printer-flash-20261115`.

## Файлы

В этой папке Git сохранены установленный `Marlin-2.1.2.8-mega2560-four-point.hex`, его конфигурации, патч и полный архив исходников `Marlin-2.1.2.8-four-point-source.zip`. Контрольные суммы HEX и архива — в `SHA256SUMS.txt`. Архив содержит Marlin, buildroot, ini, config и platformio.ini; каталог .pio и снимки EEPROM в него не входят. Для сборки распаковать архив и выполнить `pio run -e mega2560` в его корне.

- `dist/printer-four-point/Marlin-2.1.2.8-mega2560-four-point.hex` — сборка Mega2560.
- `dist/printer-four-point/SHA256SUMS.txt` — SHA-256 HEX.
- `four-point.patch` — изменения Configuration.h, G29.cpp, M115.cpp и новый математический заголовок.
- `artifacts/four-point-firmware-backup-20261115` — оригиналы изменённых файлов и предшествующий HEX.
- `dist/host-four-point/MarlinHost.App.exe` — Host 0.4 с новой галкой.

Сетка остаётся 10×9, её формат в EEPROM не изменён. Существующие настройки, включая откалиброванный E403.85, должны загружаться из прежней EEPROM. Этот HEX использует прежние конфигурационные значения по умолчанию; не выполняйте M502/M500 как часть обновления. Перед записью контроллера сохраните действующий M503 и после неё проверьте M92 и смещение Z. При выполненной записи 15 ноября EEPROM сохранилась побайтно (сравнены полные чтения до/после).

## Команды расширения

`M115` сообщает `Cap:FOUR_POINT_LEVELING:1`. Host никогда не отправляет расширенный G29 старой прошивке: старый G29 проигнорировал бы незнакомый K и запустил обычную сетку.

`G29 K0` — запрос доступных границ датчика, без перемещений и без необходимости G28:

```text
FOUR_POINT_CAPS V1 L10.00 R200.00 F20.00 B200.00
```

Значения в примере условные; прошивка рассчитывает их из действующих смещений датчика, рабочих координат, размеров стола и PROBING_MARGIN. L/R/F/B — координаты точки касания датчика, а не сопла.

`G29 K4 L... R... F... B... V1` — автоматический замер четырёх XY-точек по часовой стрелке: передняя левая, передняя правая, задняя правая, задняя левая. Повторные касания в каждой точке остаются штатными, согласно настройкам Marlin. Требуются обнулённые оси и допустимые границы. Минимальный размер прямоугольника 1 мм по каждой оси.

Новый путь использует штатную подготовку G29, снятие компенсации, BLTouch, проверки границ и завершение. На основе четырёх высот строится билинейная поверхность и все 90 значений совместимой сетки. Пока все четыре точки и уборка датчика не завершились успешно, старая сетка остаётся неизменной. При успехе прошивка включает новую компенсацию и сообщает `FOUR_POINT_OK`; при неудачном замере — `FOUR_POINT_FAILED` (ранние ошибки могут содержать только стандартное сообщение Marlin).

Обычный G29 без K продолжает выполнять штатный замер 10×9. В расширении нет M500 и нет изменения формата EEPROM. Новый замер заменяет действующую карту в RAM, а не добавляет наклон поверх прежней карты. Карта остаётся в RAM после окончания печати до следующего замера, загрузки настроек или перезапуска. За пределами области модели применяется штатное поведение билинейного выравнивания Marlin.

## Работа Host

1. Загрузить G-code. Вверху левой панели появляются границы модели и галка «Доп. выравнивание · 4 точки».
2. Отметить галку и нажать «Печать». Загрузка файла и сама галка не двигают принтер.
3. Host выполняет стартовые команды файла. Перед первой положительной подачей E он проверяет поддержку, G28 и доступные границы; ждёт заданную температуру стола и M400.
4. Прямоугольник охватывает все экструзионные траектории модели и поддержек; юбка, кайма, пользовательская продувка с меткой Custom и башня очистки исключены. К границам добавляется запас 2 мм в пределах доступности датчика. Если сама модель выходит за доступную область, замер блокируется; скрытого смещения четырёх углов внутрь модели нет.
5. После успешного замера Head возвращается к положению перед первой экструзией через подъём на 10 мм; восстанавливаются единицы, режим XYZ/E и подача. Исходный файл не изменяется.
6. Если поддержки нет, отсутствует G28, границы неизвестны, модель недоступна или нет `FOUR_POINT_OK`, первая экструзия не отправляется. Отмена ждёт текущую команду G29; аварийный стоп остаётся отдельным.

При отсутствии меток TYPE берутся все известные экструзионные траектории, поэтому продувка может расширить область. Неопознанные дуги блокируют автоматический расчёт области. Это приближённая адаптивная карта для ровного стола; четыре точки не измеряют локальную кривизну между углами.

## Сборка и проверки

```powershell
& "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe" run -d C:\Marlin\Marlin-2.1.2.8 -e mega2560 -j 4
./scripts/Build-Host.ps1 -HostOnly -OutputDirectory dist/host-four-point
dotnet run --project tests/MarlinHost.Tests -c Release -p:NuGetAudit=false -- --four-point
dotnet run --project tests/MarlinHost.Tests -c Release -p:NuGetAudit=false -- --ui --transport
```

Сборка AVR: Flash 146512/253952 байт, статическая RAM 5204/8192 байт. Тест C++ `tests/four_point_mesh.cpp` проверяет углы, горизонтальную плоскость, наклон и седло на всей сетке 10×9. Тесты Host проверяют порядок команд, исключение юбки, восстановление позиции и M83, старую прошивку, ошибку замера, недоступные границы, отсутствие G28 и отмену. Это программные проверки, а не подтверждение работы BLTouch на физическом принтере.
