# Marlin Simulator / Emulator

**Easy Marlin Emulator** — отдельный TCP-эмулятор с настоящим экраном Marlin 128×64:
запуск `Start-Easy-Marlin-Emulator.cmd`, [сборка и управление](LCD.md).
[Скачать Easy Marlin Emulator 1.0.0 для Windows x64](https://github.com/abukarenko/Marlin-Simulator/releases/tag/easy-marlin-emulator-v1.0.0).

![Marlin Emulator](assets/emulator.png)

[Скачать готовую сборку для Windows](https://github.com/abukarenko/Marlin-Simulator/releases/latest)

**Marlin Host 0.2** — отдельное приложение управления принтером: запуск `Start-Host.cmd`, [инструкция и возможности](HOST.md).

Эмулятор 3D-принтера для Windows с **настоящей прошивкой Marlin 2.1.2.9**.
Прошивка собирается в штатном окружении `simulator_windows` и работает с виртуальными
двигателями, концевиками, нагревателями и термисторами MarlinSimUI. C#-приложение
управляет подключением и передаёт байты; собственного интерпретатора G-code в нём нет.

Проект создан по образцу `../Virtual_CNC`: Windows-приложение на .NET 10,
локальная консоль и подключение через связанную пару COM-портов. Окно самого принтера
на первом этапе использует MarlinSimUI; интерфейс Virtual_CNC целиком не переносился.

## Запуск

1. Запустите `Start.cmd` или `dist/MarlinEmulator.App.exe`.
2. Для печати без Repetier-Host выберите **Локально** и нажмите **Запустить**.
   Кнопка **Открыть G-code** отправляет сохранённый из PrusaSlicer файл `.gcode` в Marlin.
   Для внешней программы выберите COM-порт и скорость либо TCP-порт и нажмите **Подключить**.
   Откроется Marlin Simulator с 3D-видом и управлением принтером.
3. В режиме COM/TCP подключите управляющую программу к выбранному TCP-порту или второму порту COM-пары.
   Команды можно также отправлять через терминал Marlin Simulator.
4. **Остановить** (локально) или **Отключить** (COM/TCP) закрывает симулятор и освобождает соединение.

В `examples/square.gcode` — квадрат 20 × 20 мм с нагревом и экструзией одного слоя.
Нагрев в симуляторе занимает время. Во время выполнения файла локальный ввод отключён.
**Аварийный стоп** отправляет `M112` немедленно, включая ожидание `M109`/`M190`.
Для восстановления после аварии закройте окно принтера и запустите его заново.

Закрытие симулятора автоматически отключает соединение. Закрытие эмулятора
освобождает порт и завершает запущенный им симулятор.
Сборка приложения требует установленного **.NET Desktop Runtime 10 x64**;
на машине разработки он уже установлен. Для 3D-окна нужен совместимый OpenGL-драйвер.

## Управляющая программа через COM

В строке **Подключение** выберите **COM** или **TCP**. Для COM задайте порт и скорость.
Для TCP задайте номер порта (по умолчанию **7000**) и нажмите **Подключить**:
эмулятор будет ожидать управляющую программу по адресу **127.0.0.1:7000**.
В управляющей программе выберите TCP и укажите этот же адрес и порт.
Кнопка **Отключить** закрывает выбранное подключение и симулятор.
Внутренний порт 8099 зарезервирован; для TCP-подключения выбирайте другой номер.

Выберите любой установленный COM-порт: физический или виртуальный. Физический порт
соединяется с управляющим компьютером последовательным кабелем с подходящей распайкой.
Для двух программ на одном компьютере используйте связанную пару виртуальных портов,
например `COM14 ↔ COM15`. Сам эмулятор драйвер не устанавливает.
При установленном com0com доступен помощник `scripts/Setup-ComPair.ps1`.

1. Выберите порт эмулятора, скорость и нажмите **Подключить**. Принтер запустится автоматически.
2. В Repetier-Host, Pronterface или другой программе выберите второй конец соединения
   (например `COM15` при `COM14` в эмуляторе), ту же скорость, **8N1**, без flow control.
3. Проверьте `M115`, `M105`, `M114`, `M119`, `G28`.

Подключение прозрачно передаёт данные в обе стороны, включая номера строк, контрольные суммы,
запросы повторной передачи и ответы прошивки. Проверку и обработку выполняет Marlin.
Проверка совместимости с конкретными внешними программами и драйверами COM — отдельный этап.
При подключённом COM-порте принтером управляет внешняя программа. Кнопка **Отключить**
освобождает порт и закрывает симулятор.
Отдельно подключать или отключать локальное управление не нужно.
При подключённом порте команды, включая `M112`, отправляются из внешней программы
или терминала в окне Marlin Simulator. Изменение DTR не имитирует перезапуск платы.

Нативный транспорт слушает только **127.0.0.1:8099**, один клиент одновременно.
Новый клиент не вытесняет уже подключённого. Для прямого TCP-клиента настройка COM не нужна.

## Виртуальный принтер

| Параметр | Значение |
|---|---|
| Прошивка | Релиз Marlin 2.1.2.9, не bugfix-ветка |
| Плата | BOARD_SIMULATED / RAMPS Native |
| Кинематика | Cartesian XYZ + E |
| Рабочая область | 220 × 220 × 250 мм |
| Экструдеры | 1 |
| Температура | Виртуальные нагреватели и термисторы сопла и стола |
| Концевики | X min, Y min, Z min, виртуальные физические контакты |
| EEPROM | M500 / M501 / M502 / M503, файл `dist/firmware/eeprom.dat` |
| Emergency parser | Включён |

Нагрев виртуального стола и всех сопел ускорен в 8 раз относительно исходной модели.
Естественное остывание сохранено; температурой по-прежнему управляет Marlin.

В 3D-превью чувствительность колеса увеличена в 10 раз. Кнопка **Clear Image**
после **Camera / Extrusion** очищает изображённую траекторию и экструзию.
Печать, положение головки и температуры при этом продолжают работать.
На стол нанесена координатная сетка с шагом 10 мм, выделением линий через 50 мм
и цветными осями X/Y. Перетаскивание левой кнопкой вращает камеру вокруг центра стола,
сохраняя расстояние до него; сброс камеры также направляет вид на центр.
Правая кнопка мыши сдвигает вид в плоскости экрана. Справа вверху показаны
координаты сопла XYZ в миллиметрах; пунктир и точка отмечают его проекцию на стол.

## Единый пульт симулятора

Панель **Simulation** содержит скорость, текущие температуры сопел и стола,
температурные уставки с **Set / Off**, концевики парами **X−/X+, Y−/Y+, Z−/Z+**
и Jog с выбором шага и подачи. Удержание кнопки концевика имитирует контакт;
реальные контакты у границ виртуального принтера также работают автоматически.
Внизу остаётся один **Monitor** для локальных команд и обмена внешней программы.
Диагностические панели доступны через **View → Panel** и по умолчанию скрыты.

**Realtime** задаёт скорость **1×**. Исправлена потеря времени при задержках Windows;
показатель **Actual** показывает измеренное отношение виртуального времени к реальному.
В проверке команда задержки на 1 секунду выполнялась за 1,005 секунды реального времени.

Настройки симулятора автоматически сохраняются в `dist/firmware/simulator.settings`,
расположение панелей — в `imgui.ini`. Сохраняются скорость, вид камеры и экструзии,
параметры поверхности стола, режимы датчиков, видимость панелей, шаг/подача Jog,
температурные уставки и размеры окна. Уставки восстанавливаются в полях ввода;
нагрев при запуске автоматически не включается. Нажатые концевики и пауза — временные состояния.
**File → Reset Default** возвращает исходные настройки интерфейса симулятора,
не изменяя EEPROM Marlin.

Основное окно запоминает COM/TCP, порт, скорость и расположение в `dist/data/ui-settings.json`.
Для его настроек также есть **Settings → Reset Default**. Подключение после запуска
выполняется кнопкой **Подключить**.

Конфигурация сохранена в `config/Configuration.h` и `config/Configuration_adv.h`.
`scripts/prepare_firmware.py` задаёт базовый профиль; меняйте параметры профиля там,
поскольку повторная подготовка обновляет соответствующие определения в прошивке.
Сохранённая EEPROM может перекрывать изменённые значения по умолчанию: для их применения
используйте `M502`, затем `M500`.

## Сборка и проверки

Требуются .NET SDK 10, Python, PlatformIO Core, встроенные Windows `curl.exe` и `tar.exe`.
Исходники Marlin и библиотек уже находятся в `vendor/`; версии и исходные хеши архивов
указаны в `SOURCES.json`. Компилятор и библиотеки MinGW размещаются в `.tools/`.
Глобальные настройки Windows и системный PATH не изменяются.

```powershell
python scripts/bootstrap_native.py
.\scripts\Build.ps1
dotnet run --project tests/MarlinEmulator.Tests -c Release -p:NuGetAudit=false
```

`Build.ps1 -HostOnly` пересобирает только C#-приложение. Готовые файлы находятся в `dist/`.
Настройка PlatformIO ищется в PATH, затем в стандартной пользовательской папке `.platformio`.
Для отдельной установки Core можно использовать `python -m pip install platformio`.

Проверка отдельно запущенной прошивки при свободном подключении:

```powershell
python scripts/smoke_firmware.py
```

Она выполняет G28, движение XYZ, нагрев сопла до 50 °C и операции EEPROM.
Журнал сохраняется в `artifacts/firmware-smoke.log`.
Дополнительная проверка `python scripts/check_emergency.py` проверяет контрольные суммы,
экструзию и M112 во время M109. После неё принтер остаётся в аварийном состоянии;
закройте и заново запустите окно симулятора.

В текущей сборке выполнены: сборка Marlin, тесты очереди команд C#, запуск и обмен
с настоящей прошивкой, G28, XYZ/E, нагрев сопла до 50 °C, EEPROM, контрольные суммы
и аварийная остановка во время нагрева. COM-соединение с внешней программой не проверено:
виртуальные COM-порты в системе отсутствовали.

## Исходники и лицензии

Основные изменения относительно upstream: профиль принтера, локальные пути сборки,
транспорт TCP для Windows с привязкой к loopback (`native/RawSocketSerialWindows.h`)
и отдельное приложение подключения. Алгоритмы G-code, планировщик и температурное
управление исполняются из исходников Marlin.

Marlin и производные части распространяются по GPL-3.0-or-later; см. `LICENSE`.
Лицензии сторонних компонентов сохранены в соответствующих папках `vendor/`.
Скрипт настройки COM-пары перенесён из Virtual_CNC. Драйвер COM в комплект не входит.

Иконки эмулятора и симулятора находятся в `assets/`; их можно пересоздать через
`scripts/Build-Icons.ps1`. Они созданы для этого проекта.
